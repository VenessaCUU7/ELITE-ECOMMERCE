# ELITE COMMERCE UG - Professional E-commerce Platform

## Overview
A complete, professional e-commerce platform built with vanilla JavaScript, HTML, and CSS. Features separate admin and customer portals, image upload capability, and Uganda Shillings (UGX) currency.

## Features

### Customer Portal
- Browse products with images and descriptions
- Add/remove items from cart
- Adjust quantities in cart
- Place orders
- View order confirmation

### Admin Dashboard
- Product management (add, delete)
- Image upload for products
- View all customer orders
- Sales statistics (total products, orders, revenue)
- Clear all orders functionality

### Security
- Separate login portals for customers and admins
- Demo credentials included
